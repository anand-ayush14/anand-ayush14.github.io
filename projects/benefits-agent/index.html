Card Benefits Agent

Premium cards now come with many small credits that reset monthly, quarterly or twice a year, and members say they are hard to keep track of. This agent tracks every credit, warns before money expires, picks the best card for each purchase and checks whether a card is worth its annual fee. The same tools run as an MCP server that any AI assistant can call.

How it works

Architecture

cards.json: each credit's amount, reset period (monthly / quarterly / semi-annual / annual), eligible merchants, enrollment.
engine.py: matches each transaction to at most one credit on the card used (most specific merchant match), then rolls usage up by period.
4 tools: get_unused_credits, year_to_date, value_vs_fee, recommend_card_for_purchase.
mcp_server.py: exposes the tools over the Model Context Protocol, so Claude Desktop or any agent can use them.
agent.py: a Claude tool-use loop; the model decides which tool to call.

Why this matters for an issuer

  1. Retention: members who use few credits are the ones who cancel at renewal. The fee check flags them months ahead, so the bank can nudge them instead of offering a costly retention deal at the last minute.
  2. Engagement: a nudge a week before a credit expires turns unused value into card spend at partner merchants.
  3. Agentic commerce: exposing benefits as tools lets AI assistants pick the right card at checkout, which is where card networks are heading.
  4. Co-brand gap: the same tracker works for co-brand cards (here, Delta Reserve), not only the flagship card.
