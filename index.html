Featured · LLMs & RAG

Edge SLM: chat with your documents, fully offline

A private, offline document assistant that runs quantized small language models on a Raspberry Pi. No cloud and no internet.

  • Extended deepsense.ai's open-source RAG pipeline (MIT) with FAISS retrieval and quantized TinyLlama 1.1B and Qwen 2.5 1.5B models.
  • Built a Streamlit web UI and a Raspberry Pi edition with a Bash installer, desktop launcher and Docker image.
  • Improved response latency and matched each model with its prompt template, so answers stay grounded in the retrieved documents.
